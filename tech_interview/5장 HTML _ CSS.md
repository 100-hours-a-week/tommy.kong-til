### !DOCTYPE이 무엇인지 설명해주세요.
- !DOCTYPE(document type)은 HTML 문서 가장 첫번째 줄에 위치해야 하며, 문서의 버전과 유형을 정의하는 HTML 태그입니다. 
- 각 브라우저에서 문서 간의 호환성을 높이고, HTML 문서를 동일하게 인식할 수 있게 선언하기 위해 사용 


### HTML의 data-속성의 목적을 설명해주세요. 
- HTML의 data-속성은 DOM 요소에 특정한 사용자 정의 데이터를 저장하는 표준화한 방법을 제공 

### id와 class의 차이점을 설명해 주세요. 
- id는 전체 페이지에서 하나의 유일한 요소에 적용하고 class는 복수의 요소에 적용할 때 사용 

### CSS에서 박스 모델에 대해 설명해 주세요 .
- css에서 박스 모델이란 웹 페이지의 요소들을 사각형 박스로 표현하는 방식입니다. 
- html의 요소들은 박스로 이뤄져 있고 이 박스는 4개의 영역으로 이뤄져 있음 
	- 마진(margin)
	- 테두리(border) 
	- 패딩(padding) 
	- 콘텐츠 영역(content) 

### css에서 position을 어떻게 사용하는지 설명해 줘.
- css에서 html 문서 상에서 요소가 배치되는 방식을 결정하기 위해 position 속성을 사용함. 
- 요소의 정확한 위치 지정을 위해 top, left, bottom, right등의 속성과 함께 사용하며 static, relative, absolute, fixed, sticky 총 5가지 값고 함께 쓰임.
