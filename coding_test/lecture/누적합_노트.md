# 누적합(Prefix Sum)

## 1. 개념
누적합(Prefix Sum)은 배열에서 특정 구간의 합을 빠르게 구하기 위해 사용하는 기법이다. 
기본적인 아이디어는 **이전 값을 기억하여 연산을 최적화**하는 것이다. 

## 2. 누적합의 원리
일반적으로 배열의 부분합을 구하려면 반복문을 사용해야 하므로 **O(N)** 시간이 소요된다. 하지만 **누적합 배열을 미리 계산하면 O(1)** 시간에 구간합을 구할 수 있다.

- 원본 배열: `arr = [3, -2, -4, -9, 0, 3, 7, 13, 8, -3]`
- 누적합 배열: `prefix[i] = prefix[i-1] + arr[i]`

  예를 들어, `prefix[5] - prefix[2]`를 계산하면 **arr[3]부터 arr[5]까지의 합**을 빠르게 구할 수 있다.

## 3. 누적합 구현 방법
### 1차원 누적합 (Prefix Sum)
```python
n, r = map(int, input().split())
arr = list(map(int, input().split()))
prefix = [0] * (n + 1)

for i in range(n):
    prefix[i + 1] = prefix[i] + arr[i]

max_sum = max(prefix[k] - prefix[k - r] for k in range(r, n + 1))
print(max_sum)
```
위 코드는 **연속된 r개의 부분합 중 최대값**을 구하는 방식이다.

### 2차원 누적합 (2D Prefix Sum)
2차원 배열에서도 누적합을 활용할 수 있다. 이를 통해 직사각형 범위의 합을 **O(1)** 시간에 계산할 수 있다.

```python
n = 4
grid = [
    [1, 2, 3, 4],
    [2, 3, 4, 5],
    [3, 4, 5, 6],
    [4, 5, 6, 7]
]
x1, y1, x2, y2 = 2, 2, 3, 4

prefix = [[0] * (n + 1) for _ in range(n + 1)]

for i in range(n):
    for j in range(n):
        prefix[i+1][j+1] = prefix[i][j+1] + prefix[i+1][j] - prefix[i][j] + grid[i][j]

result = prefix[x2][y2] - prefix[x1-1][y2] - prefix[x2][y1-1] + prefix[x1-1][y1-1]
print(result)
```
위 코드는 `(x1, y1) ~ (x2, y2)` 영역의 합을 구하는 방식이다.

## 4. 응용 문제
### (1) 수열의 특정 간격 내 최대 합 (#2559)
```python
a, b = map(int,input().split())
arr = list(map(int,input().split()))
prefix = [0] * (a+1)

for i in range(a):
    prefix[i+1] = prefix[i] + arr[i]

answer = max(prefix[k] - prefix[k-b] for k in range(b, a+1))
print(answer)
```

### (2) 연속된 부분합 중 최대값 (#1912)
```python
n = int(input())
numbers = list(map(int, input().split()))
prefix = [-1001] * (n+1)

for i in range(n):
    prefix[i+1] = max(prefix[i] + numbers[i], numbers[i])

print(max(prefix))
```

### (3) 이모스법을 활용한 장애물 경주 (#3020)
```python
n, h = map(int, input().split())
line = [0] * h

for t in range(n):
    height = int(input())
    if t % 2 == 0:
        line[0] += 1
        line[height] -= 1
    else:
        line[h-height] += 1

prefix = [0] * (h+1)
for i in range(h):
    prefix[i+1] = prefix[i] + line[i]

print(min(prefix[1:]), prefix.count(min(prefix[1:])))
```
이모스법을 활용하면 특정 구간에 **차이를 기록하는 방식**으로 장애물의 개수를 빠르게 계산할 수 있다.

## 5. 누적합을 활용한 문제 해결 전략
1. **구간합을 자주 계산해야 하는 문제**에서 사용.
2. **2차원 배열에서도 활용 가능**, 직사각형 내의 합을 O(1)로 구할 수 있음.
3. **이모스법(Imos Method)** 등과 결합하면 구간에 영향을 주는 연산도 빠르게 처리 가능.

누적합을 활용하면 반복문을 줄이고 **시간 복잡도를 대폭 개선할 수 있다.**
