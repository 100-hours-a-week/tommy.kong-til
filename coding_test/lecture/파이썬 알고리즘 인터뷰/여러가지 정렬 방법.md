# 여러가지 정렬 방법

- 파이썬은 팀소트를 기반으로 실제 데이터를 매우 빠르게정렬

- 실제 데이터는 대부분 이미 정렬되어 있을 것이다'라고 가정 하고 실제 데이터에서 고성능을 낼 수 있도록 설계한 알고리즘

- sorted() 
	- 파이썬 리스트나 문자열을 정렬해서 다시 리스트의 형태로 반환 

```python 
a = [2,5,1,9,7]
sorted(a)
[1,2,5,7,9]
```
- key 옵션을 지정해 정렬을 위한 키 또는 함수를 별도로 지정가능

```python 
c = ['ccc','aaaa','d','bb']
sorted(c, key=len)
['d','bb','ccc','aaaa'] # 길이 순서로 정렬된다. 
```

```python
a = ['cde', 'cfc', 'abc']

def fn(s):
	return s[0], s[-1]

print(sorted(a,key=fn))

['abc','cfc','cde']
# 첫 문자열로 정렬 한뒤 같을 시 마지막 문자열 순으로 정렬 

sorted(a, key = lambda s : (s[0], s[-1]))
# 이런 식으로 람다로도 가능하다. 
```

- sort()
	- 리스트 작체를 정렬
	- 입력을 출력으로 덮어 쓰기 때문에 별도의 추가 공간이 필요x
		- 이러한 측면에서 sorted()와는 다름 

```python 
a = [2,5,1,9,7]
a.sort() # 가능
blist = a.sort() #None을 출력하기 때문에 불가능 
```
