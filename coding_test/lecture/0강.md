# Python Input and Output

## 입력 (Input)
Python에서 입력을 받을 때는 `input()` 함수를 사용하며, 기본적으로 문자열(string) 형태로 입력을 받습니다.

### 1. 단순한 정수 입력
```python
number = int(input())
```
- `input()`을 사용하여 입력을 받고, `int()`를 사용하여 정수형으로 변환합니다.

### 2. 여러 개의 정수 입력 (수열)
```python
first, second, third = map(int, input().split())
list1 = list(map(int, input().split()))
```
- `input().split()`을 사용하여 입력을 공백 기준으로 나누고, `map(int, ...)`을 이용해 정수형으로 변환합니다.
- `list(map(int, input().split()))`를 사용하면 여러 개의 정수를 리스트로 저장할 수 있습니다.

### 3. 단순한 문자열 입력
```python
string = input()
```
- 문자열을 그대로 입력받습니다.

### 4. 여러 개의 문자열 입력
```python
first, second, third = map(str, input().split())
list2 = list(map(str, input().split()))
```
- 문자열 여러 개를 공백 기준으로 나누어 입력받습니다.
- `map(str, input().split())`을 사용하여 리스트 형태로 저장할 수도 있습니다.

## 출력 (Output)
### 1. 리스트 출력
```python
print(*list1)
print(*list2)
```
- `print(*list)`를 사용하면 리스트 내부의 요소들을 공백을 두고 출력할 수 있습니다.

## 반복문 (Loop)
### 1. for 반복문
```python
for _ in range(200):
    print('hi')
```
- `_`는 반복에서 변수를 사용하지 않을 때 쓰는 관례적인 이름입니다.
- `range(200)`을 사용하면 200번 반복합니다.

### 2. while 반복문
```python
while _ < 10:
    print(_)
    _ = _ + 1
```
- `_ < 10` 조건이 참일 동안 실행됩니다.
- `_ = _ + 1`을 통해 `_` 값을 증가시켜 조건을 만족하지 않을 때 반복이 종료됩니다.

## 조건문 (Conditional Statements)
```python
name = 't'
if name == 't':
    print(f"your name is {name}")
else:
    print(f'your name is not {name}')
```
- `if` 문을 사용하여 조건을 확인하고, 참이면 해당 블록을 실행합니다.
- `else`를 사용하여 조건이 거짓일 경우 다른 블록을 실행합니다.
- `f"{변수}"` 형식의 f-string을 사용하여 문자열을 쉽게 출력할 수 있습니다.
