# 시계열 데이터 분석이 데이터를 시간 기반으로 이해하는 데 중요한 이유를 설명하시오.
## 시계열 데이터란?
- 시계열 데이터란 <span style="background:#fff88f">일정한 시간 간격</span>에 따른 정보량을 기록한 데이터
	- 일정한 시간 간격이란?
		- 매일, 매분기, 매년 등 <span style="background:#fff88f">데이터가 기록된 간격이 동일</span>해야한다. 
- 분석의 관점에서는 독립변수가 시간으로 고정된 데이터
- 판다스의 관점에서 본다면 시간을 index로 가진 데이터
- 사용되는 데이터가 발생된 시간에 의해 순서가 명확함
## 시계열 데이터을 사용하는 이유?
- <span style="background:#fff88f">시간의 흐름</span>에 따라 <span style="background:#fff88f">과거 데이터를 확인</span>하고 앞으로 <span style="background:#fff88f">데이터가 어떻게 흘러갈 것 인가를 예측</span>하기 위해 사용 
- 그러면 시계열 데이터에서 예측이란?
	-  과거의 데이터 <span style="background:#fff88f">패턴</span>이 유사하게 지속된다는 가정하에 <span style="background:#fff88f">미래 특정한 기간의 데이터 흐름을 분석</span>하기 위해 사용
	- 패턴을 찾는 과정
		- 데이터에서 예측 가능한 특성(패턴)을 뽑아내고 예측 분가능한 특성(노이즈)을 제거하는 과정
		- 혹은 $y_{t} = f(y_1,...,y_{t-1}) + 노이즈$가 있을때 이 f를 찾는것
		- f을 예측하는 데 여러 기법들이 있는 데 이 기법을 선택하는 방법은 무엇일까?
			- 이는 내가 보려는 패턴에 따라 달라짐. 
## 시계열 데이터의 패턴
그러면 내가 보려고 하는 패턴이 무엇일까?
이는 시계열 데이터가 시간이라는 특징때문에 다른 데이터와 달리 가지고 있는 패턴을 의미한다. 
그러한 패턴에는 다음과 같은 것이 있다. 
1. 자기상관성
	1. 한 변수의 이전 값과 현재 값 사이의 상관관계를 나타냄.
	2. 과거의 데이터가 현재의 데이터에 영향을 주는 경향이 있음
	3. 특히, 시계열 데이터는 인접한 시간 데이터간에 상관관계가 존재하는 경우가 많음
	4. 이렇게 시계열 데이터는 인접한 시간 간격의 값들이 서로 밀접하게 연결되어 있는 경우가 많아 과거의 패턴이나 추세가 앞으로도 지속될 가능성을 예측하는 데 중요한 역할을 하기도 함.
	5. ex)
	6. 예를 들어, 최근 우리나라의 출생아 수나 전체 학생 수가 매년 줄어들고 있는 추세를 보인다고 할 때, 재작년보다 작년의 수가, 그리고 작년보다 올해의 수가 줄어든다면, 이는 과거 데이터가 현재 데이터에 영향을 미치고 있음을 보여줍니다. 
	7. 그림 1-5의 예를 보면, 199년부터 2020년까지의 우리나라 유·초·중·고등학교 전체 학생 수를 나타낸 표와, 1년 전 전체 학생 수와 현재 전체 학생 수를 비교한 플롯에서, 1년 전의 학생 수가 증가하면 현재 학생 수도 증가하는 관계가 매우 뚜렷하게 나타납니다. 이러한 강한 선형 관계는 자기상관성이 매우 높다는 것을 의미합니다.
2. 추세
	1. 장기적으로 점차 증가하거나 점차 감소하는 추세를 보이는 경우가 많음 
	2. 데이터에서 우리가 원하는 것이 바로 이러한 추세를 발견하는 것 그리고 이러한 추세를 찾아서 미래에 어떻게 대응할지에 대한 정보를 얻을 수 있음.
3. 계절성, 주기성
	1. 계절성 :  봄, 여름, 가을, 겨울과 같은 계절, 일, 주, 월, 분기와 같은 기간의 변화 등에 따라 주기적으로 변동하는 시계열 → 고정된 기간에 대한 주기적 반복  
	2. 주기성 : 일정한 기간과는 상관 없이 데이터의 변동성이 반복되거나 1년을 넘겨 주기적으로 발생하는 데이터의 반복성 → 변동적 기간에 대한 주기적 반복
4. 불확실성
	1. 미래 예측값은 현재로서는 정확히 모른다.  
	2. . 시계열 모델의 해석에는 반드시 불확실성에 대한 고려가 수반되어야함 → 여기서 주로 사용되는 게 신뢰 구간이다.

## 시계열 데이터의 종류 
문가가 데이터를 시각화한 뒤에 직접 확인하면 되지 않을까? 굳이 모델링을 할 필요가 있을까? 
시계열 데이터를 분류해보면, 
- 비정상성 데이터
	- 추세, 계절성 등 시계열적 특성을 보유한 데이터 
	- 시간에 따라 평균, 분산이 달라짐
- **정상성 데이터 (Stationary Data)** 
	- 관측된 시간과 무관하게 생성된 데이터 
	- 평균, 분산 등 통계적 특성이 시간에 따라 일정함 
	- 시계열적 특성이 없는 데이터
단순 시각화만으로는 알기 어려운 점이 있기 때문에 모델링 과정을 거치는 것이 중요
## 시계열 모델링과 정상성 
- **시계열 모델링의 목표** - **비정상성 데이터를 정상성 데이터로 변환** - 예: 추세, 계절성을 차분, 로그 변환 등을 통해 제거 - 변환 과정에서 시계열 데이터의 다양한 특성(추세, 계절성 등)을 파악하고 모델링 - **정상성으로 전환 후 남은 데이터(잔차)** - 예측의 불확실성을 나타내는 오차(백색잡음)로 간주 - 예측 기간이 길어질수록 오차가 누적되어, **예측 구간이 점점 넓어짐**
### 왜 모델링이 필요한가? 
- **시각화**를 통해 거시적인 패턴(추세, 계절성 등)을 어느 정도 파악할 수 있으나, - **정량적인 미래 예측**이나 **오차(불확실성) 추정**을 위해서는 모델링이 필수 - 모델링을 통해 **예측 구간(신뢰 구간)**을 설정할 수 있고, - 정책 수립, 비즈니스 의사결정 등에 활용 가능 결국, 시계열 데이터를 이해하고 예측하는 과정에서 단순 시각화만으로는 파악하기 어려운 미래 예측 및 불확실성까지 고려하기 위해 **정량적 모델링**이 꼭 필요합니다.



**비정상을 정상 데이터로 나타내는 방법들의 대표적인 방법**  
대표적인 방법은 지연(lag)과 차분(difference)

![[Pasted image 20250214114650.png]]

지연은 데이터를 정해진 시간만큼 앞으로 당기거나 혹은 뒤로 밀어낸 데이터를 말한다. 지연은 데이터의 자기상관성(autocorrelation)을 측정하기 위해 필수적으로 필요한 과정이다.

**차분**

![[Pasted image 20250214114712.png]]

차분은 연속된 관찰값들 간의 차이를 말한다. 비정상성 시계열 데이터를 정상성으로 만드는데 일반적으로 사용되는 방법으로, 전년 대비 증감량, 전월 대비 증감량과 같이 특정한 시간 간격의 데이터와의 차이를 나타낸다.

**적합값 (fitted value)**  
적합값은 시계열 분석을 통해 생성된 시계열 모델에 과거 시간을 대입하여 생성된 과거에 대한 예측값이다. 실제 관측된 값과 모델이 추정한 값과의 차이가 발생한다. 이 값이 잔차(residuals)다. 잔차는 시계열 모델의 성능과 정확성을 평가하기 위해 사용된다.

**백색잡음 (white noise)**  
백색잡음은 추세, 계절성, 자기상관성 등의 시계열적 특성이 모두 제거된 데이터를 말한다. 결국, 백색잡음은 더 이상 모델링으로 추상화할 수 없는 시계열 데이터로, 값을 예측할 수 없고 랜덤하게 발생되는 값들이다. 잘 모델링된 시계열 모델에서 발생된 잔차는 백색잡음이어야 하기 때문에 오류값이라고 여겨지기도 한다.

백색잡음은 시간의 흐름에 따라 영향받지 않는 독립적 데이터이어야 하며, 시간의 변화에 관계없이 평균은 0, 분산은 1로 일정하게 유지된다. 하지만 사실상 정확히 평균 0, 분산 1이 유지되는 것은 아니고, 대략 평균 0, 분산 1에서 큰 변화가 없다는 것으로 받아들이는 것이 좋다.


## 시계열 데이터가 왜 중요한가?
- 우리는 **시간의 흐름 속에서 살아가기 때문에** 시간적 변화에 따라 미래의 결과를 예측하는 것은 정부의 정책을 수립하거나 기업에서 비즈니스 전략을 수립하는 과정에서 많이 사용되고 있음

그래서 필연적이다.

나의 답변에 참고해야할 사항들

시계열데이터분석에서우리가가장원하는것이데이터가그동안어떤추세를보 였고이추세가유지된다면앞으로어떻게미래에대응해야할지를결정하기위한정보

따라서시계열모델의해석에는반드시불확실성에대한고려가수반되어야한다. 시계열분석
을통해예측된미래데이터는사용된모델에적합한확률분포probabitydistribution에따른 신뢰구 간이같이제공되어평가되어야한다.

예측값을 얻으면, 확률변수(random variable)가 가질 수 있는 가능한 값들의 범위에서 _가운데_를 추정합니다. 종종 예측값은 확률변수(random variable)가 비교적 높은 확률로 취할 수 있는 값들의 _범위_를 제시하는 **예측구간(prediction interval)**을 수반합니다. 예를 들어, 95% 예측구간은 95% 확률로 실제 미래의 값을 포함할 값의 범위를 제시합니다.

시간에 대해 $t$ 라는 아래첨자를 사용하겠습니다. 예를 들어, $y_t$ 는 시간 $t$ 에서의 관측값을 나타냅니다. 우리가 관측한 모든 정 보를 $\mathcal{I}$ 로, 우리가 예측하고 싶은 것을 $y_t$ 로 씁시다. 그리고 "우리가 아는 $\mathcal{I}$ 이 주어진 상황에서의 무작위 변수 $y_t$ "를 의미 하는 $y_t \mid \mathcal{I}$ 를 씁시다. 상대적인 확률 값에 따라 이 무작위 변수가 가질 수 있는 값은 $y_t \mid \mathcal{I}$ 의 "확률분포(probability distribution)"라고 합니다. 예측할 때, 이것을 예측분포(forecast distribution)라고 부릅니다.
"예측"을 말할 때, 보통은 예측분포(forecast distribution)의 평균을 가리키고, 나타낼 때 $y$ 위에 "모자 기호 (hat)"을 씌웁니다. 따라서, $y_t$ 의 예측을, 우리가 아는 모든 것에서 $y_t$ 가 가질 수 있는 가능한 값의 평균을 의미하는 $\hat{y}_t$ 로 씁니다. 가끔, $\hat{y}_t$ 를 예측 분포의 중간값median (또는 중앙값) 대신에 $\hat{y}_t$ 로 쓸 것입니다.


1단계: 문제 정의.

예측 작업에서 종종 이 단계가 가장 어려운 부분이 됩니다. 신중하게 문제 정의할 때에는 예측값이 어떤 방식으로 사용될지, 누가 예측값을 요구하는지, 예측 함수가 예측값을 요구하는 조직에 얼마나 잘 어울릴지를 모두 이해할 필요가 있습니다. 예측하는 사람은 데이터 수집 과정, 데이터베이스 유지 보수, 예측값 제공 방식 등을 미래 계획 수립 담당자 모두와 시간을 내서 대화할 필요가 있습니다.

2단계: 정보 수집.

항상 최소한으로 요구되는 데이터 종류에는 두 가지가 있습니다: (1) 통계 데이터, (2) 데이터를 모으고 예측값을 사용하는 사람들에게 축적된 전문지식. 좋은 통계 모델을 맞출 수 있는 과거 데이터를 충분히 모으는 것이 종종 힘들 수 있습니다. 이러한 경우에는 [4](https://otexts.com/fppkr/judgmental.html#judgmental) 장의 판단예측(judgmental forecasting) 기법을 사용할 수 있습니다. 가끔, 오래된 데이터는 예측하려는 시스템에 구조적인 변화가 생겨서 쓸모 없을 수도 있습니다; 이 때는 가장 최근의 데이터만 선택해서 사용해야 하겠습니다. 하지만, 좋은 통계 모델은 시스템의 변화도 다룰 수 있다는 것을 기억하시길 바랍니다. 좋은 데이터를 불필요하게 버리는 일이 없기를 바랍니다.

3단계: 예비(탐험적; exploratory) 분석.

항상 데이터를 그래프로 나타내는 것으로 시작하시길 바랍니다. 일관된 패턴이 존재합니까? 의미 있는 추세(trend)가 존재합니까? 계절성(seasonality)이 중요합니까? 경기 순환(business cycle)이 존재한다는 증거가 있습니까? 데이터에 전문적인 지식으로 설명할 수 있는 어떤 특이점들이 있습니까? 분석에 사용할 수 있는 변수 사이의 관계가 얼마나 강합니까? 이러한 분석을 돕는 다양한 도구가 존재합니다. [2](https://otexts.com/fppkr/graphics.html#graphics) 와 [6](https://otexts.com/fppkr/decomposition.html#decomposition) 장에서 이러한 것들을 다룹니다.

4단계: 모델을 선택하고 맞추기.

과거 데이터를 이용할 수 있는 정도, 예측 변수(forecast variable)와 설명 변수(explanatory variable) 사이 관계의 강도, 그리고 예측값이 사용될 방식에 따라 사용할 가장 좋은 모델이 달라집니다. 각 모델 자체는 몇 가지 (명시적인 그리고 암시적인) 가정에 기초한 것이며, 보통은 알려진 과거 데이터를 사용해서 반드시 계산해야 하는 하나 이상의 매개변수를 포함합니다. 회귀(regression) 모델( [5](https://otexts.com/fppkr/regression.html#regression) 장), 지수 평활(exponential smoothing) 기법( [7](https://otexts.com/fppkr/expsmooth.html#expsmooth) 장), Box-Jenkins ARIMA 모델( [8](https://otexts.com/fppkr/arima.html#arima) 장), 동적 회귀(dynamic regression) 모델( [9](https://otexts.com/fppkr/dynamic.html#dynamic) 장), 계층적(hierarchical) 예측( [10](https://otexts.com/fppkr/hierarchical.html#hierarchical) 장), 신경망(neural network), 벡터 자기회귀(vector autoregression)를 포함한 몇 가지 고급 기법을 다룰 것입니다( [11](https://otexts.com/fppkr/advanced.html#advanced) ).

5단계: 예측 모델을 사용하고 평가하기.

모델을 선택하고, 모델의 매개변수를 추정한 다음에는, 예측값을 내는 용도로 모델을 사용합니다. 모델의 성능은 예측한 기간에 대한 데이터를 사용할 수 있게 될 때만 제대로 평가할 수 있습니다. 예측의 정확도를 평가할 수 있도록 돕는 기법이 존재합니다. 예측값을 사용하고 예측값에 영향을 주는 회사 차원의 문제도 있습니다. [3](https://otexts.com/fppkr/toolbox.html#toolbox) 장에서 이러한 문제 몇 가지를 간단하게 살펴봅니다. 실제 상황에서 예측 모델을 사용할 때는, 결측치(또는 빠진 값; missing values)과 이상값(outlier)를 처리하는 방법 또는 짧은 시계열을 다루는 방법 같은 수많은 실제적인 문제가 등장합니다. 이러한 경우는 [12](https://otexts.com/fppkr/practical.html#practical) 장에서 다룹니다.
