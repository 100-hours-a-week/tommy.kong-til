# 시계열 데이터 분석이 데이터를 시간 기반으로 이해하는 데 중요한 이유를 설명하시오.
## 시계열 데이터란?
- 시계열 데이터란 <span style="background:#fff88f">일정한 시간 간격</span>에 따른 정보량을 기록한 데이터
	- 일정한 시간 간격이란?
		- 매일, 매분기, 매년 등 <span style="background:#fff88f">데이터가 기록된 간격이 동일</span>해야한다. 
- 분석의 관점에서는 독립변수가 시간으로 고정된 데이터
- 판다스의 관점에서 본다면 시간을 index로 가진 데이터
- 사용되는 데이터가 발생된 시간에 의해 순서가 명확함
## 시계열 데이터을 사용하는 이유?
- <span style="background:#fff88f">시간의 흐름</span>에 따라 <span style="background:#fff88f">과거 데이터를 확인</span>하고 앞으로 <span style="background:#fff88f">데이터가 어떻게 흘러갈 것 인가를 예측</span>하기 위해 사용 
- 그러면 시계열 데이터에서 예측이란?
	-  과거의 데이터 <span style="background:#fff88f">패턴</span>이 유사하게 지속된다는 가정하에 <span style="background:#fff88f">미래 특정한 기간의 데이터 흐름을 분석</span>하기 위해 사용
	- 패턴을 찾는 과정
		- 데이터에서 예측 가능한 특성(패턴)을 뽑아내고 예측 분가능한 특성(노이즈)을 제거하는 과정
		- 혹은 $y_{t} = f(y_1,...,y_{t-1}) + 노이즈$ 가 있을때 이 $f$를 찾는것
		- 여리서 노이즈는 모델로 설명할 수 없는 줄일 수 없는 무작위 변동(불확실성)을 의미함.
		- f을 예측하는 데 여러 기법들이 있는 데 이 기법을 선택하는 방법은 무엇일까?
			- 이는 내가 보려는 패턴에 따라 달라짐. 
## 시계열 데이터의 패턴
그러면 내가 보려고 하는 <span style="background:#fff88f">패턴</span>이 무엇일까?
이는 시계열 데이터가 시간이라는 특징때문에 다른 데이터와 달리 가지고 있는 패턴을 의미한다. 
그러한 패턴에는 다음과 같은 것이 있다. 

1. **자기상관성**
	- 과거의 값이 현재 값에 미치는 영향을 의미
	- 한 변수의 이전 값과 현재 값 사이의 상관관계를 통해 평가
	- 시간 순서에 따라 기록되었다는 시계열 데이터의 특성을 보면 <span style="background:#fff88f">일반적으로 인접한 시점간 강한 상관관계를 보임</span>
	- **과거의 패턴이 미래에도 지속될 가능성이 높음을 예측할 수 있으며, 이를 활용해 보다 정교한 예측 모델을 설계할 수 있음**
2. **추세**
	- 시계열 데이터는 장기적으로 점차 증가하거나 점차 감소하는 추세를 보이는 경우가 많음 
	- 우리가 원하는 것이 바로 이러한 추세를 발견하는 것 그리고 이러한 **추세를 찾아서 미래에 어떻게 대응할지에 대한 정보를 얻을 수 있음**
	- 예를 들어 대한민국의 출산율을 보면 감소하는 추세를 보임
3. **계절성, 주기성**
	- 계절성 :  봄, 여름, 가을, 겨울과 같은 계절, 일, 주, 월, 분기와 같은 기간의 변화 등에 따라 주기적으로 변동하는 시계열 → 고정된 기간에 대한 주기적 반복  
		- 예를 들어 취업자수의 경우 상반기, 하반기 채용 시즌때 증가하고 비시즌때는 감소하는 계절성이 있음
	- 주기성 : 일정한 기간과는 상관 없이 데이터의 변동성이 반복되거나 1년을 넘겨 주기적으로 발생하는 데이터의 반복성 → 변동적 기간에 대한 주기적 반복
		- 예를 들어 경기순환 모델을 보면 일정한 패턴은 없지만 반복적인 변동성이 존재함
	- **계절성과 주기성을 모델링에 반영함으로써, 주기적인 변화에 따른 미래 값을 보다 정확하게 예측**
## 시계열 데이터의 종류와 모델링 
**시계열 데이터를 단순히 시각화하면, 그 안에 숨겨진 추세나 계절성이 바로 눈에 띄지 않을까?**  
굳이 복잡한 모델링 과정을 거칠 필요는 없지 않을까? 혹은  과연 모든 시계열 데이터가 명확하게 패턴을 드러낼까?
실제로 데이터마다 내재된 추세, 계절성, 주기성 또는 자기상관성과 같은 패턴이 뚜렷하게 나타나지 않는 경우가 많음.
추세나 계절성이 존재하더라도 통계적 특성(평균, 분산, 공분산 등)이 시간에 따라 변화하는 데이터는 **비정상성 데이터**로 분류됨.(여기서 비정상성이란 non-stationary의 의미임)
**여기서 비정상성 데이터란?** 
- 추세, 계절성 등 시계열적 특성이 존재할 수 있으나, 시간에 따라 평균, 분산, 또는 공분산 등 통계적 특성이 변화하는 시계열 데이터 
- 이러한 변화로 인해 단순 시각화만으로는 데이터 내의 패턴을 명확하게 파악하기 어려움
**비정상성이 있으면 정상성이 있는데 정상성 데이터란?**
- 데이터의 통계적 특성 예를 평균, 분산, 공분산이 시간에 관계없이 일정한 데이터
**왜 이런 구분을 지은 것일까?**
- **대부분의 시계열 예측 모델은 정상성 가정을 전제**
- 비정상성 데이터를 정상성으로 전환하기 위해 **래그,차분 변환 등의 기법을 사용하며**, 변환 후 모델의 잔차가 **백색잡음** 에 가까워진다면, 이는 모델이 데이터의 패턴을 효과적으로 포착했다는 의미임 -> 여기서 백색잡음은 수식 **$y_{t} = f(y_1,\dots,y_{t-1}) + \text{노이즈}$의 노이즈 항이 되는 것. 그리고 여기서 찾은 f가 계절성, 주기성 등의 패턴인 것**
- 이는 회귀분석과 비슷하다고 볼 수 있음.
	- 회귀모델에서도 잔차에 대한 몇가지 가정이 있는데 시계열 데이터를 정상성으로 전환하는 과정 또한 회귀분석에서 잔차의 독립성과 일정한 분산(등분산성)을 확보하기 위한 전처리 과정과 유사한 역할을 한다고 볼 수 있음
- **결국, 시계열 모델링은 비정상성 데이터를 정상성 데이터로 전환하는 과정을 통해 숨겨진 패턴을 찾아내고 이를 바탕으로 미래 데이터를 예측하는 중요한 과정임.**
<span style="background:#fff88f">- 이렇게 비정상성 데이터를 정상성 데이터로 전처리하여 숨겨진 패턴을 추출하는 다양한 모델링 기법들이 있는 것.</span>
# 모델링이 중요한 이유? 그리고 확률
예측하려는 대상이 사전에 알려져 있다면 예측할 필요가 없지만, 실제로는 미래의 값들이 불확실한 상태이므로, 이들에 대해 가능한 여러 결과와 그 확률을 고려하게 됨. 
즉, 여기서 미래의 값은 하나의 확률 변수이자 function이고 따라서 예측값에 대한 분포와 신뢰구간이 있음. 
결국 확률적 접근은 가까운 미래와 먼 미래에 따른 예측의 불확실성 차이를 반영하며, 보다 현실적이고 신뢰할 수 있는 예측을 가능하게함.
예측의 정확성은 영향을 주는 요인을 얼마나 잘 이해하고 있는지, 사용할 수 있는 데이터가 충분한지, 그리고 예측 자체가 대상에 영향을 미치는지 등에 따라 달라짐.
이러한 확률변수의 정확성 그리고 노이즈를 최대한 줄이는 과정을 통해 이를 통해 예측의 정확성을 높이는 과정을 통해 모델링을 해야함.
더나아가. 시계열 데이터는 시간에 따라 변화하는 패턴(추세, 계절성, 주기성, 자기상관성 등)을 내포하고 있기 때문에, 이를 분석하면 과거의 패턴이 미래에도 반복될 가능성을 바탕으로 향후 변동을 예측할 수 있기 때문에 모델링 하는게 중요하다. 

# 시계열 데이터 분석이 데이터를 시간 기반으로 이해하는 데 중요한 이유를 설명하시오.
따라서 시계열 데이터 분석은 데이터의 시간적 흐름을 깊이 이해하고 미래 변동에 효과적으로 대응할 수 있는 필수적인 접근법이다. 이를 통해 단기적 안정성뿐만 아니라 장기적 불확실성까지 반영한 효율적이고 효과적인 계획 수립이 가능해지므로, 데이터를 시간 기반으로 이해하는 데 시계열 분석은 매우 중요하다.
