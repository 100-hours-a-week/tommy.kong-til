## **Streamlit을 로컬에서 실행하는 방법** 

**1. Pipenv를 이용해 가상 환경에서 Streamlit 설치** 

```python
pipenv install streamlit
# 혹은 기존 환경 집입 후 설치
pipenv shell 
pip install streamlit
```

**2. Streamlit 서버 실행**
```
streamlit run main.py
```

**3. 브라우저에서 Streamlit 앱 확인**
- 기본적으로 `http://localhost:8501`에서 실행됨
```python
streamlit run main.py --server.port 8080
```

**4. (선택) 로컬 네트워크에서 접근 가능하도록 설정**
```python
streamlit run main.py --server.address 0.0.0.0 --server.port 8501
```

##  **Streamlit 배포 방법 (Cloud)**
로컬 실행이 아니라 **배포(public)** 을 원할 경우 다음 방법을 사용할 수 있음.
 **1. Streamlit Community Cloud 사용 (무료)**
- Streamlit 공식 배포 플랫폼을 사용하여 `GitHub`에서 직접 배포 가능.
- GitHub에 코드를 올리고 Streamlit Cloud에서 프로젝트를 생성하면 됨.
 
**2. Heroku / AWS / GCP 배포**
```python
pip install gunicorn gunicorn -w 2 -k uvicorn.workers.UvicornWorker main:app
```
- Streamlit은 자체적으로 배포 서버 기능을 제공하므로 **보통 gunicorn 없이 실행 가능**.
- 하지만 **Cloud 환경에서는 `Docker`를 사용하여 배포**하는 것이 일반적.
### 세션
웹 개발에서 **Session(세션)** 은 **사용자의 상태를 일정 기간 동안 유지하는 방법**을 의미합니다. 일반적으로 웹은 **HTTP 프로토콜을 사용**하며, HTTP는 **stateless(상태를 저장하지 않음)** 특성이 있기 때문에, 사용자가 페이지를 이동할 때마다 정보가 초기화됩니다. 이를 해결하기 위해 **세션(Session)** 이 사용됩니다.

- **사용자가 웹사이트에 접속하면 서버가 세션을 생성하고, 고유한 세션 ID(Session ID)를 부여함.**
- **서버는 세션 ID를 이용해 사용자의 데이터를 유지**할 수 있음.
- **세션은 일정 시간이 지나면 자동으로 만료됨** (예: 30분 동안 활동이 없으면 로그아웃됨).

```scss
사용자 → (로그인 요청) → 서버 (세션 생성, 세션 ID = abc123 발급)
서버 → (세션 ID를 쿠키로 전달) → 사용자
사용자 → (다음 요청) → 서버 (세션 ID 확인 후 사용자 정보 유지)
```

### 추가적으로 할 수 있는 것들
- google 로그인 구현
```python
import streamlit as st
from google_auth_oauthlib.flow import Flow
from google.oauth2.credentials import Credentials
import os
import requests

# Streamlit 앱의 제목 설정
st.title('Google Login with Streamlit')

# credentials 객체를 저장 가능한 형태로 변환하는 함수


def credentials_to_dict(credentials):
    return {
        'token': credentials.token,
        'refresh_token': credentials.refresh_token,
        'token_uri': credentials.token_uri,
        'client_id': credentials.client_id,
        'client_secret': credentials.client_secret,
        'scopes': credentials.scopes,
        'id_token': credentials.id_token
    }


# OAuth 설정 변수 정의
# 구글 클라우드 콘솔에서 받은 OAuth 클라이언트 정보 JSON 파일
CLIENT_SECRETS_FILE = "client_secret.json"
SCOPES = ["openid", "https://www.googleapis.com/auth/userinfo.email",
          "https://www.googleapis.com/auth/userinfo.profile"]
REDIRECT_URI = 'http://localhost:8501'  # Streamlit 앱이 실행되는 로컬 주소

# credentials가 Streamlit 세션 상태에 없는 경우, 인증 절차 시작
if 'credentials' not in st.session_state:
    # Google OAuth Flow 객체 생성
    flow = Flow.from_client_secrets_file(
        CLIENT_SECRETS_FILE,
        scopes=SCOPES,
        redirect_uri=REDIRECT_URI
    )

    # 사용자에게 제공할 Google 인증 URL 생성
    auth_url, _ = flow.authorization_url(prompt='consent')

    # Streamlit 앱에 Google 로그인 버튼 표시
    st.link_button('Login with Google', auth_url)

    # 사용자가 Google 로그인을 완료하고 돌아오면 URL에서 인증 코드(code)를 받아 토큰을 요청
    query_params = st.query_params
    if 'code' in query_params:
        flow.fetch_token(code=query_params['code'])
        credentials = flow.credentials
        # 얻은 credentials를 세션 상태에 저장하여 로그인 상태 유지
        st.session_state['credentials'] = credentials_to_dict(credentials)
        # 앱을 재실행하여 로그인 상태를 반영
        st.rerun()

# 이미 로그인한 경우, 저장된 credentials를 사용해 사용자 정보를 가져옴
else:
    credentials = Credentials(**st.session_state['credentials'])

    # Google API에서 사용자 정보를 요청하는 endpoint 설정
    userinfo_endpoint = "https://www.googleapis.com/oauth2/v3/userinfo"

    # credentials를 이용하여 사용자 정보 요청
    response = requests.get(
        userinfo_endpoint,
        headers={"Authorization": f"Bearer {credentials.token}"}
    )

    # 요청이 성공했을 경우, 사용자 정보를 추출해 화면에 표시
    if response.status_code == 200:
        userinfo = response.json()
        st.success('Logged in successfully!')
        st.write(f"Your email: {userinfo['email']}")
        st.write(f"Your name: {userinfo.get('name', 'No name provided')}")
        # 사용자 프로필 사진이 있으면 화면에 표시
        if 'picture' in userinfo:
            st.image(userinfo['picture'])
    else:
        # 사용자 정보 요청이 실패한 경우 오류 메시지 출력
        st.error('Failed to fetch user info.')

    # 로그아웃 버튼을 클릭하면 세션에서 credentials를 삭제하여 로그아웃 처리
    if st.button('Logout'):
        del st.session_state['credentials']
        st.rerun()
```
